# Student Performance Analytics System

## 1. Project Objective

The objective of this project is to analyze student performance using Python, Pandas, and NumPy.

## 2. Technologies Used

* Python
* Pandas
* NumPy
* CSV Dataset
* Visual Studio Code

## 3. Dataset

The project uses a CSV file named `students.csv` containing 20 student records.

The dataset includes:

* Student ID
* Student Name
* Department
* Python Marks
* Mathematics Marks
* Statistics Marks
* SQL Marks
* Computer Science Marks
* Attendance

## 4. Project Features

* Load student records using Pandas.
* Display dataset information and basic statistics.
* Calculate total and average marks.
* Assign grades based on average marks.
* Calculate Pass/Fail results.
* Count passed and failed students.
* Identify the highest and lowest performers.
* Calculate subject-wise average marks.
* Display the top five students.

## 5. How to Run the Project

1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy`
3. Keep `main.py` and `students.csv` in the same folder.
4. Open the project folder in VS Code.
5. Run the command:
   `python main.py`

## 6. Learning Outcomes

Through this project, I practiced Python functions, conditional statements, loops, Pandas DataFrames, CSV file handling, and NumPy calculations.

## 7. Conclusion

This project demonstrates basic student performance analysis using Python, Pandas, and NumPy.
